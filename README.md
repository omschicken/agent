# shorts-agents

Пайплайн агентов: CS2-видео -> нарезка хайлайтов -> 9:16 с баннером сайта и пометкой 18+ -> тексты под платформу -> публикация.

## Установка
1. Python 3.11+ и ffmpeg (в PATH).
2. `pip install -r requirements.txt`
3. `ANTHROPIC_API_KEY` в переменных окружения.
4. Для YouTube: `client_secret.json` из Google Cloud (YouTube Data API v3).

## Запуск
Положите видео в `inbox/` (опционально рядом `имя.txt` с описанием момента и источником).

    python main.py                # DRY_RUN: только нарезка и тексты в out/
    DRY_RUN=0 python main.py      # + публикация (YouTube сначала как private)

## Агенты
- `curator` - ищет пики громкости (хайлайты)
- `editor` - ffmpeg: 9:16, баннер, дисклеймер
- `copywriter` - Claude: заголовок/описание/хэштеги
- `publisher` - YouTube API (готово), TikTok/Instagram (заглушки)

## Важно
Берите только материал, на который у вас есть права или разрешение (свои записи, договорённости с авторами, политики клипов организаторов). Указывайте источник. Реклама кейс-сайта должна идти с 18+ и соблюдать правила платформ.
