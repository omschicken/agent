# shorts-agents

Агенты для нарезки шортсов по CS2: записи стримов -> поиск рейджей/смешного/хайлайтов -> 9:16 с баннером сайта и 18+ -> тексты под платформу -> публикация.

## Установка
1. Python 3.11+, ffmpeg и deno (для YouTube) в PATH: `winget install Gyan.FFmpeg DenoLand.Deno`
2. `pip install -r requirements.txt` (для видеокарты NVIDIA ещё `pip install nvidia-cublas-cu12 "nvidia-cudnn-cu12==9.*"`; нужен `av<17`)
3. Переменная окружения `ANTHROPIC_API_KEY`.
4. Для публикации на YouTube: `client_secret.json` (Google Cloud, YouTube Data API v3).

## Запуск
    python main.py --scout        # сам находит и скачивает записи стримов, нарезает (DRY_RUN: ничего не постит)
    python main.py                # нарезка видео, уже лежащих в inbox/
    DRY_RUN=0 python main.py      # + публикация (YouTube сначала как private)

## Как это работает
1. **scout** - берёт свежие видео с каналов из `sources.yaml` (белый список авторов); Claude по названию отсеивает не-CS2, новости, розыгрыши.
2. **judge (источник)** - Claude смотрит кадры: это CS2? нет чужих сайтов/рекламы/розыгрышей? не разговор/настройки?
3. **moments** - Whisper (GPU) расшифровывает речь, Claude читает расшифровку и выбирает рейджи, смешное, хайлайты с точными границами и подводкой.
4. **judge (клип)** - повторная проверка кадров клипа.
5. **editor** - ffmpeg: 9:16, размытый фон, баннер, дисклеймер 18+.
6. **copywriter** - Claude: заголовок/описание/хэштеги (без выдуманных бонусов), в тексте цитата момента и источник.
7. **publisher** - YouTube API готов; TikTok/Instagram - заглушки.

## Настройки (`config.yaml`)
- `clip.mode`: `transcript` (записи стримов) или `scenes` (нарезка по сценам/громкости, для роликов-сборников)
- `clip.whisper_model`: `large-v3-turbo` для GPU; `small`/`base` для процессора
- `judge.*`: правила проверки кадров (`curated` - упрощённые правила для белого списка, `allow_webcam`)
- `scout.whitelist_only`: брать только каналы из `sources.yaml`

## Утилиты
- `resolve_channels.py ник1 ник2` - найти YouTube-каналы по никам
- `find_channels.py` - какие каналы выдаются по темам
- `check_shorts.py`, `run_test.py` - проверки и тестовый прогон

## Важно
Источник и автор указываются в описании. Используйте материал, на который у вас есть права или разрешение авторов. Реклама кейс-сайта должна идти с 18+ и по правилам платформ.
